# Kiana Akbarzade — Portfolio

Bilingual (EN/FA) personal portfolio built with React, TypeScript, Vite, Tailwind CSS, and i18next.

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Build

```bash
npm run build
npm run preview
```

## Customize later

- **Photo:** add `public/photo.jpg` and set `PHOTO_SRC` in `src/components/Avatar.tsx`
- **CV:** add `public/cv.pdf` and set `resumeUrl` in `src/data/links.ts`
- **Copy:** edit `src/i18n/locales/en.json` and `fa.json`
